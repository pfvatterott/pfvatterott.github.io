## 🏔️ Overview

A clean, minimalist personal site built with modern HTML5, custom CSS (Glassmorphism & Dark Mode), and Vanilla JavaScript (ES6+). Highlights current work as a **Support Engineer at PropelAuth** (managing SDKs in React, JS, Node, Python, Rust, Go, writing technical docs, and authoring AI MCP servers), paired with a background in Customer Engineering (BetterCloud), Technical Support (ClickUp), and Outdoor Expedition Leadership.

## ✨ Key Features

- **Interactive Canvas Topography**: High-performance particle canvas responding to mouse movements.
- **Glassmorphism Design System**: Dark mode theme with vibrant cyan accents (`#00f2fe`) and modern typography (Outfit & Plus Jakarta Sans).
- **Technical Skills Matrix**: Filterable skills matrix categorized by Frontend, Backend & DB (Node, Python, Rust, Go), and Tools & SaaS platforms (PropelAuth, MCP Servers, BetterCloud, ClickUp).
- **Career & Leadership Timeline**: Structured overview of roles including Support Engineer at PropelAuth, Customer Engineering at BetterCloud, Technical Support at ClickUp, and Outdoor Expedition Leadership.
- **In-Browser Resume Viewer**: Interactive modal displaying resume pages and direct PDF downloads.
- **Click-to-Copy Contact Utilities**: Instant copy-to-clipboard functionality with toast notifications for email and phone.
- **Fully Responsive**: Mobile-first responsive layout with custom drawer navigation.
